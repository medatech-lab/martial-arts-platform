# 🐉 Project Dragon

# Design System

Version: 0.1

Status: In Bearbeitung

Autor: MeDaTech

---

# 1. Design Philosophie

Die Website soll nicht wie eine gewöhnliche Fitness- oder Kampfsportseite wirken.

Sie soll eine hochwertige Marke repräsentieren.

Die Besucher sollen bereits nach wenigen Sekunden folgende Eigenschaften wahrnehmen:

- Vertrauen
- Disziplin
- Stärke
- Eleganz
- Professionalität
- Qualität
- Moderne

Das Design soll zeitlos wirken und auch in mehreren Jahren noch modern aussehen.

---

# 2. Zielgruppe

Die Website richtet sich an:

- Kinder
- Jugendliche
- Erwachsene
- Anfänger
- Fortgeschrittene
- Wettkämpfer
- Selbstverteidigung
- Fitnessinteressierte

Das Design muss deshalb sowohl seriös als auch einladend wirken.

---

# 3. Designsprache

Nicht aggressiv.

Nicht überladen.

Nicht verspielt.

Stattdessen:

- klar
- hochwertig
- elegant
- modern
- ruhig
- selbstbewusst

Weniger ist mehr.

Jedes Element soll einen Zweck erfüllen.

---

# 4. Markenwerte

Die gesamte Website orientiert sich an folgenden Werten:

- Respekt
- Disziplin
- Gemeinschaft
- Qualität
- Leidenschaft
- Tradition
- Moderne

Jede Designentscheidung soll diese Werte unterstützen.

---

# 5. Farbwelt

Primärfarben

- Schwarz
- Anthrazit
- Weiß

Sekundärfarben

- Hellgrau

Akzentfarbe

- Dezentes Rot

Die Akzentfarbe wird ausschließlich für wichtige Aktionen verwendet.

Beispiele:

- Probetraining
- Jetzt buchen
- Wichtige Hinweise

Die Website soll überwiegend schwarz-weiß bleiben.

---

# 6. Typografie

Große, elegante Überschriften.

Klare und gut lesbare Fließtexte.

Großzügige Zeilenabstände.

Keine verspielten Schriftarten.

Die Schrift soll modern und hochwertig wirken.

---

# 7. Layout

Viel Weißraum.

Große Bereiche.

Klare Struktur.

Saubere Ausrichtung.

Keine überfüllten Seiten.

---

# 8. Komponenten

Alle Komponenten werden selbst entwickelt.

Dazu gehören unter anderem:

- Buttons
- Navigation
- Hero
- Karten
- Formulare
- Footer
- Dialoge
- Dashboard-Komponenten

Ziel ist ein eigenes UI-System.

---

# 9. Animationen

Animationen sollen dezent eingesetzt werden.

Beispiele:

- sanftes Einblenden
- weiche Übergänge
- leichtes Schweben
- Hover-Effekte

Keine hektischen Animationen.

Keine blinkenden Elemente.

---

# 10. Responsive Design

Mobile First.

Optimiert für:

- Smartphone
- Tablet
- Laptop
- Desktop
- große Bildschirme

Alle Inhalte müssen auf jeder Bildschirmgröße optimal dargestellt werden.

---

# 11. Barrierefreiheit

Die Website soll:

- gut lesbar sein
- ausreichende Kontraste besitzen
- große Klickflächen bieten
- mit Tastatur bedienbar sein
- moderne Webstandards erfüllen

---

# 12. Ziel

Die Besucher sollen den Eindruck haben:

"Hier trainiere ich bei einer professionellen Kampfsportschule."

Nicht:

"Hier wurde einfach eine Website gebaut."

Die Website soll die Qualität der Schule widerspiegeln.

---

# 13. Designprinzipien

Bei jeder neuen Seite und jeder neuen Komponente gelten folgende Grundregeln:

1. Weniger ist mehr.
2. Jede Farbe hat einen Zweck.
3. Jede Animation unterstützt die Benutzererfahrung.
4. Einheitlichkeit ist wichtiger als Individualität.
5. Mobile First.
6. Gute Lesbarkeit hat immer Vorrang.
7. Wiederverwendbare Komponenten statt doppeltem Code.
8. Qualität vor Geschwindigkeit.

---

# 14. Designentscheidung

Die Website soll sich optisch von typischen Kampfsport-Websites unterscheiden.

Kein aggressives "Fight Club"-Design.

Stattdessen entsteht der Eindruck einer hochwertigen Premium-Marke, die Professionalität, Disziplin und Vertrauen vermittelt.
